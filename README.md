# Веб-технологии — Полюшко Кирилл, группа 932402

Вариант 10: «Книжный червь и писатель».

Открыть `Polushko.html` или `index.html` в браузере. Установка пакетов не нужна.
Исходная первая лабораторная сохранена в `lab1/Polushko.html` вместе с её стилями и изображением.

## Лабораторная №2 — CSS

- Внешний `style.css`, внутренний `<style>` для нумерованного списка проектов и inline `max-width: 100%` у изображения.
- В `:root` заданы цвета и шрифты; основная гамма — бежевая и коричневая.
- `static` у заголовков, `relative` у контейнеров, `absolute` у сторон карточек и бейджа.
- Карточки проектов переворачиваются через `rotateY(180deg)` при наведении и фокусе; на телефоне — при нажатии.
- Поле «Имя» пульсирует при фокусе. Есть состояния `:hover`, `:active`, `:focus`, `:visited`.
- Клавиатурная навигация, подписи полей, заметный фокус и отключение анимации по настройке `prefers-reduced-motion`.

Проверено в Chromium: загрузка изображения, переворот карточки, анимация поля, отсутствие горизонтальной прокрутки при ширине 360, 768 и 1280 px.

## Лабораторная №3 — Flexbox и Grid

- `nav` с горизонтальным меню на Flexbox; пункты переносятся при недостатке места.
- «Книги на полке»: три семантические карточки `<article>` на Flexbox, в каждой обложка, название, автор, статус и заметка.
- Собственные условные SVG-обложки находятся в `images/covers/`; внешние изображения и шрифты не загружаются.
- «Цитаты недели»: CSS Grid из трёх `<figure>` с `<blockquote>`, автором и названием книги в `<cite>`.
- Карточки: одна в строке до 600 px, две от 601 до 900 px, три от 901 px.
- Цитаты: одна колонка до 600 px, три на остальных размерах — согласно варианту 10.

Проверено в Chromium на 320, 375, 600, 601, 768, 900, 901 и 1280 px: число колонок, загрузка обложек и отсутствие горизонтальной прокрутки.
