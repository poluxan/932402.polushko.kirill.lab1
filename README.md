## Лабораторная №2 — CSS

- Внешний `style.css`, внутренний `<style>` для нумерованного списка проектов и inline `max-width: 100%` у изображения.
- В `:root` заданы цвета и шрифты; основная гамма — бежевая и коричневая.
- `static` у заголовков, `relative` у контейнеров, `absolute` у сторон карточек и бейджа.
- Карточки проектов переворачиваются через `rotateY(180deg)` при наведении и фокусе; на телефоне — при нажатии.
- Поле «Имя» пульсирует при фокусе. Есть состояния `:hover`, `:active`, `:focus`, `:visited`.
- Клавиатурная навигация, подписи полей, заметный фокус и отключение анимации по настройке `prefers-reduced-motion`.

Проверено в Chromium: загрузка изображения, переворот карточки, анимация поля, отсутствие горизонтальной прокрутки при ширине 360, 768 и 1280 px.
