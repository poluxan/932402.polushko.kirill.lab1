# Лабораторная работа №1 — Основы HTML и структура веб-страницы

вариант 10 (Книжный червь и писатель)

## Что реализовано

- Семантическая структура: `header`, `main`, `section`, `aside`, `footer`
- Секция «Навыки» — маркированный список
- Секция «Проекты» — нумерованный список (книги, по которым хотел бы снять фильм/написать продолжение)
- `aside` — любимый автор
- Изображение с атрибутами `src`, `alt`, `width`, `height`
- Форма обратной связи (имя, email, сообщение)
- Стилизация в кофейно-бежевой гамме (CSS)

## Технологии

- HTML5
- CSS3
