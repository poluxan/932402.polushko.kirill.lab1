## Лабораторная №2 — CSS

- Внешний `style.css`, внутренний `<style>` для нумерованного списка проектов и inline `max-width: 100%` у изображения.
- В `:root` заданы цвета и шрифты; основная гамма — бежевая и коричневая.
- `static` у заголовков, `relative` у контейнеров, `absolute` у бейджа и ссылки перехода к содержимому.
- Карточки проектов переворачиваются через `rotateY(180deg)` при наведении и фокусе; на телефоне — при нажатии.
- Поле «Имя» пульсирует при фокусе. Есть состояния `:hover`, `:active`, `:focus`, `:visited`.
- Клавиатурная навигация, подписи полей, заметный фокус и отключение анимации по настройке `prefers-reduced-motion`.

Проверено в Chromium: загрузка изображения, переворот карточки, анимация поля, отсутствие горизонтальной прокрутки при ширине 360, 768 и 1280 px.

## Лабораторная №3 — Flexbox и Grid

- `nav` с горизонтальным меню на Flexbox; пункты переносятся при недостатке места.
- «Книги на полке»: три семантические карточки `<article>` на Flexbox, в каждой обложка, название, автор, статус и заметка.
- Собственные условные SVG-обложки находятся в `images/covers/`; внешние изображения и шрифты не загружаются.
- «Цитаты недели»: CSS Grid из трёх `<figure>` с `<blockquote>`, автором и названием книги в `<cite>`.
- Карточки: одна в строке до 600 px, две от 601 до 900 px, три от 901 px.
- Цитаты: одна колонка до 600 px, три на остальных размерах — согласно варианту 10.

Проверено в Chromium на 320, 375, 600, 601, 768, 900, 901 и 1280 px: число колонок, загрузка обложек и отсутствие горизонтальной прокрутки.

## Лабораторная №4 — JavaScript

`script.js` подключён с `defer`. Массив `pagesPerDay` содержит семь значений: `[18, 65, 42, 0, 80, 55, 30]`.

- `findMaximum` находит максимум циклом и условием.
- `filterHighPaceDays` отбирает значения строго больше 50.
- `sumPages` подсчитывает сумму.
- `analyzeReading` считает среднее, число дней с количеством страниц ≤ 20 и их долю. Внутри используется цикл `for`.
- `renderReadingStatistics` показывает результаты на странице.
- `runReadingDemo` вызывает `prompt` для имени, `alert` с приветствием и `alert` с итогом; подробности выводит `logReadingStatistics` через `console.log`.
- При среднем строго больше 40 в консоль выводится «Отличный темп чтения!».
- Отмена ввода имени обработана отдельно; пустое имя заменяется на «читатель».

### Как показать работу

1. Открыть `Polushko.html` и перейти к разделу «Дневник чтения».
2. Открыть инструменты разработчика: F12 → Console.
3. Нажать «Показать статистику», ввести имя и закрыть приветствие.
4. В следующем `alert` появится: «Всего прочитано 290 страниц, в 3 днях темп был высоким».

Диалоги запускаются кнопкой, а результаты расчётов видны сразу при загрузке страницы.

Пример вывода в консоль:

```text
Прочитано страниц по дням: [18, 65, 42, 0, 80, 55, 30]
Максимум за день: 80
Дни с высоким темпом (> 50 страниц): [65, 80, 55]
Количество «ленивых» дней: 2
Доля «ленивых» дней: 28,57%
Среднее количество страниц: 41,43
Отличный темп чтения!
```

Результат: сумма 290, максимум 80, среднее 290 / 7 ≈ 41,43; высокий темп в 3 днях; «ленивых» дней 2 из 7, их доля 2 / 7 ≈ 28,57%.

### Проверки и отладка

Для открытия страницы Node.js не нужен. Если он установлен, автоматические проверки можно запустить так:

```sh
node --check script.js
node --test tests/script.test.cjs
```

Шесть тестов проверяют основной пример, границы 20 и 50, неделю без чтения, пустой массив, сохранность исходных данных и условие «среднее > 40». Дополнительные npm-пакеты не требуются.

Для пошаговой отладки открыть F12 → Sources → `script.js`, поставить точку останова в `analyzeReading` и нажать «Показать статистику». Через Step over (F10) можно проследить значения `index`, `lazyDaysCount`, `totalPages` и возвращаемый объект. Чтобы проверить ветви условий, изменить массив, сохранить файл и обновить страницу.

В браузере проверены: prompt/alert/console, отмена и пустое имя, вывод имени как текста, форма обратной связи без отправки данных, переворот карточек, фокус, `prefers-reduced-motion` и загрузка всех ресурсов. На ширинах от 320 до 1920 px нет горизонтальной прокрутки и обрезанного текста карточек. Контраст проверенных цветов текста — не менее 4,5:1.

Форма обратной связи учебная: после заполнения показывает локальное подтверждение; серверная отправка не реализуется в этих работах.
